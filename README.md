# FitLife_Gym

## Descripción
FitLife Gym es un proyecto de desarrollo web enfocado en el diseño de una página para un gimnasio. Su objetivo es presentar información sobre los servicios y actividades, mediante una interfaz visual atractiva y fácil de navegar.

## Características
- Página de inicio con presentación del gimnasio.
- Secciones informativas sobre servicios destacados.
- Diseño visual enfocado en el ámbito fitness.
- Menú de navegación para facilitar el acceso a las diferentes secciones.
- Elementos gráficos e imágenes relacionados con el ejercicio y la actividad física.

## Tecnologías utilizadas
- HTML5: estructura de la página.
- CSS3: diseño y estilos visuales.
- JavaScript: funcionalidades e interactividad.

## Instalación y ejecución
1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo `index.html` en tu navegador.
